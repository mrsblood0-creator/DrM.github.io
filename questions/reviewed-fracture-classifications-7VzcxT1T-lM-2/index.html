Odontoid classification: 2

Choose the single best answer, then reveal the explanation.

A patient has a fracture at the junction of the dens and the body of C2. The clinician notes that this location carries an important nonunion risk. Which Anderson-D’Alonzo category identifies the base-of-dens injury?

  1. Anderson-D’Alonzo type I
  2. Anderson-D’Alonzo type III
  3. Hangman fracture
  4. C1 ring fracture
  5. Anderson-D’Alonzo type II
Reveal answer and explanation
Correct answer

Anderson-D’Alonzo type II

Type II crosses the base of the dens and carries an important nonunion risk.

Understanding the options

Anderson-D’Alonzo type II
Type II crosses the base of the dens and carries an important nonunion risk.
Anderson-D’Alonzo type I
Type I is an odontoid tip fracture; associated ligamentous injury must still be considered. This does not best answer the specific question in this case.
Anderson-D’Alonzo type III
Type III extends into the cancellous body of C2. This does not best answer the specific question in this case.
Hangman fracture
A hangman injury involves the C2 pars region rather than an isolated dens fracture. This does not best answer the specific question in this case.
C1 ring fracture
An atlas ring fracture involves C1 rather than the odontoid process of C2. This does not best answer the specific question in this case.
