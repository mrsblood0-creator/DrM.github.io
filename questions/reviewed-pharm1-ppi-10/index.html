A misleading neuroendocrine marker

Choose the single best answer, then reveal the explanation.

A patient taking omeprazole has an elevated chromogranin A result during investigation of nonspecific symptoms. Imaging is unrevealing. Which medication effect should be addressed before interpreting the marker as definitive evidence of a neuroendocrine tumor?

  1. Only acute bacterial infection can raise the marker
  2. PPI-related acid suppression can increase chromogranin A
  3. Omeprazole crosslinks every tumor-marker assay
  4. PPI use guarantees an occult malignancy
  5. Chromogranin A is unaffected by medications
Reveal answer and explanation
Correct answer

PPI-related acid suppression can increase chromogranin A

PPI-associated hypergastrinemia can elevate chromogranin A; labeling recommends a temporary interruption before testing when clinically appropriate.

Understanding the options

PPI-related acid suppression can increase chromogranin A
PPI-associated hypergastrinemia can elevate chromogranin A; labeling recommends a temporary interruption before testing when clinically appropriate.
Omeprazole crosslinks every tumor-marker assay
The effect is physiologic rather than universal assay crosslinking.
PPI use guarantees an occult malignancy
A medication-associated rise does not establish cancer.
Chromogranin A is unaffected by medications
PPIs are an important confounder.
Only acute bacterial infection can raise the marker
The marker has several nonmalignant influences.
