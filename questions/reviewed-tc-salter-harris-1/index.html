salter harris — pattern 1

A 9-year-old child has focal growth-plate pain after a twisting injury. Further imaging shows separation confined entirely to the physis, without a fracture line through the adjacent metaphysis or epiphysis. The articular surface itself remains intact. Which Salter–Harris type is represented?

  1. Type III
  2. Type IV
  3. Type V
  4. Type I
  5. Type II
Answer and explanation

Type I

Type I: A fracture through the physis alone, without metaphyseal or epiphyseal extension.

Option explanations

Type I: Type I: A fracture through the physis alone, without metaphyseal or epiphyseal extension.

Type II: Type II describes a fracture through the physis that exits through the metaphysis. The case instead matches Type I.

Type III: Type III describes a fracture through the physis and epiphysis that reaches the articular surface. The case instead matches Type I.

Type IV: Type IV describes a fracture crossing metaphysis, physis and epiphysis, including the joint surface. The case instead matches Type I.

Type V: Type V describes a compression or crush injury of the physis, often recognized through later growth disturbance. The case instead matches Type I.
