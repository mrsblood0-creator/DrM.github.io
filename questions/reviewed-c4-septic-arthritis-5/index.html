Drainage and source control

A 49-year-old patient has culture-confirmed bacterial infection of a native knee with a large purulent effusion. Antibiotics have been started. Which additional management principle addresses the infected material and reduces intra-articular bacterial burden?

  1. Joint drainage with orthopedic assessment
  2. Permanent immobilization without reassessment
  3. Routine steroid injection into the infected joint
  4. Stop antibiotics as soon as fever falls
  5. Treat only the serum inflammatory marker
Answer and explanation

Joint drainage with orthopedic assessment

Source control is a key part of managing a purulent infected joint.

Option explanations

Joint drainage with orthopedic assessment: Source control is a key part of managing a purulent infected joint.

Permanent immobilization without reassessment: This does not remove infected material.

Routine steroid injection into the infected joint: This is not source control and can worsen infection.

Stop antibiotics as soon as fever falls: Early symptomatic improvement does not prove eradication.

Treat only the serum inflammatory marker: Management must address the joint infection itself.
