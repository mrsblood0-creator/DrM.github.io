Radial head fractures: 2

Choose the single best answer, then reveal the explanation.

A patient has a displaced fracture involving part of the radial head. The remaining head is intact rather than globally comminuted, and there is no elbow dislocation. Which Mason type best matches this partial-articular pattern?

  1. Mason type I
  2. Mason type III
  3. Mason type IV in the modified classification
  4. Essex-Lopresti injury
  5. Mason type II
Reveal answer and explanation
Correct answer

Mason type II

A displaced partial radial head fracture is type II; mechanical block and stability affect treatment.

Understanding the options

Mason type II
A displaced partial radial head fracture is type II; mechanical block and stability affect treatment.
Mason type I
An undisplaced or minimally displaced radial head fracture without mechanical block is type I. This does not best answer the specific question in this case.
Mason type III
A comminuted radial head fracture involving the whole head is type III. This does not best answer the specific question in this case.
Mason type IV in the modified classification
A radial head fracture associated with elbow dislocation is type IV in the modified system. This does not best answer the specific question in this case.
Essex-Lopresti injury
Radial head fracture with interosseous membrane disruption and DRUJ injury causes longitudinal forearm instability. This does not best answer the specific question in this case.
