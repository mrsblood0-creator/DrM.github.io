A misleading bronchodilator response

A preschooler has persistent unilateral wheeze that improves slightly after albuterol but never resolves. Symptoms began after a sudden coughing episode during play. There is no prior asthma history. How should the partial treatment response be interpreted?

  1. Associated bronchospasm may improve even if an object remains
  2. A partial bronchodilator response establishes asthma as the only diagnosis
  3. Albuterol can dislodge an object by relaxing the bronchial wall
  4. A residual focal wheeze is an expected finding after complete recovery
  5. Response to bronchodilation distinguishes food from plastic aspiration
Answer and explanation

Associated bronchospasm may improve even if an object remains

Reactive bronchospasm around an aspirated object may improve while the mechanical obstruction remains.

Option explanations

Associated bronchospasm may improve even if an object remains: Reactive bronchospasm around an aspirated object may improve while the mechanical obstruction remains.

A partial bronchodilator response establishes asthma as the only diagnosis: Response to bronchodilation is not specific enough to override a choking history and persistent focal signs.

Albuterol can dislodge an object by relaxing the bronchial wall: Bronchodilator treatment does not provide reliable foreign-body removal.

A residual focal wheeze is an expected finding after complete recovery: Persistent focal findings indicate ongoing pathology and should not be assumed to represent recovery.

Response to bronchodilation distinguishes food from plastic aspiration: The response cannot determine the object material or exclude aspiration.
