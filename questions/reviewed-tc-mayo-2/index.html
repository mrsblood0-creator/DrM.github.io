Choose the single best answer, then reveal the explanation.

An older adult has posterior elbow pain after a fall. CT shows several olecranon fragments, but the fracture remains nondisplaced and the ulnohumeral joint is stable. The assessment distinguishes comminution from displacement when assigning the Mayo subtype. Which Mayo olecranon fracture subtype best describes these findings?

  1. Type IIIA
  2. Type IIIB
  3. Type IB
  4. Type IIA
  5. Type IIB
Reveal answer and explanation
Correct answer

Type IB

Type IB: A nondisplaced, comminuted olecranon fracture.

Understanding the options

Type IB
Type IB: A nondisplaced, comminuted olecranon fracture.
Type IIA
Type IIA describes a displaced, noncomminuted olecranon fracture with a stable ulnohumeral joint. The case instead matches Type IB.
Type IIB
Type IIB describes a displaced, comminuted olecranon fracture with a stable ulnohumeral joint. The case instead matches Type IB.
Type IIIA
Type IIIA describes a displaced, noncomminuted olecranon fracture with ulnohumeral instability. The case instead matches Type IB.
Type IIIB
Type IIIB describes a displaced, comminuted olecranon fracture with ulnohumeral instability. The case instead matches Type IB.
