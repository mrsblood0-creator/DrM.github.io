Distinguishing conduction disease

A 70-year-old has fatigue and a ventricular rate of 38/min. ECG shows regular P waves at 76/min, but every second P wave is not followed by a QRS. Conducted beats have the same PR interval. Which description best captures this tracing?

  1. Atrial fibrillation
  2. Respiratory sinus arrhythmia
  3. Sinus tachycardia
  4. Second-degree atrioventricular block with 2:1 conduction
  5. Sinus bradycardia with normal AV conduction
Answer and explanation

Second-degree atrioventricular block with 2:1 conduction

There are twice as many atrial depolarizations as ventricular responses, indicating 2:1 AV block; the strip alone does not classify Mobitz type reliably.

Option explanations

Second-degree atrioventricular block with 2:1 conduction: There are twice as many atrial depolarizations as ventricular responses, indicating 2:1 AV block; the strip alone does not classify Mobitz type reliably.

Sinus bradycardia with normal AV conduction: True sinus bradycardia with intact conduction would conduct each sinus P wave.

Atrial fibrillation: Organized P waves exclude atrial fibrillation.

Respiratory sinus arrhythmia: Respiratory sinus arrhythmia does not drop every second ventricular response.

Sinus tachycardia: The atrial rate is not tachycardic.
