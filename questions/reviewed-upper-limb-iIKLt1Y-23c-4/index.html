Radial head fractures: 4

Choose the single best answer, then reveal the explanation.

A patient with a radial head fracture also reports wrist pain. Examination and imaging identify interosseous membrane disruption and distal radioulnar instability. Which combined injury must be recognized before treating the elbow injury as isolated?

  1. Mason type III
  2. Mason type IV in the modified classification
  3. Essex-Lopresti injury
  4. Mason type I
  5. Mason type II
Reveal answer and explanation
Correct answer

Essex-Lopresti injury

Radial head fracture with interosseous membrane disruption and DRUJ injury causes longitudinal forearm instability.

Understanding the options

Mason type I
An undisplaced or minimally displaced radial head fracture without mechanical block is type I. This does not best answer the specific question in this case.
Mason type II
A displaced partial radial head fracture is type II; mechanical block and stability affect treatment. This does not best answer the specific question in this case.
Mason type III
A comminuted radial head fracture involving the whole head is type III. This does not best answer the specific question in this case.
Mason type IV in the modified classification
A radial head fracture associated with elbow dislocation is type IV in the modified system. This does not best answer the specific question in this case.
