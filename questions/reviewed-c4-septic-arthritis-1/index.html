Sampling before antibiotics in a stable patient

Choose the single best answer, then reveal the explanation.

A 64-year-old man has an acutely swollen, hot knee with painful restriction of movement. He is hemodynamically stable without sepsis, and joint aspiration can be performed immediately. Which sequence best preserves microbiologic diagnostic yield?

  1. Wait several days for spontaneous improvement
  2. Inject intra-articular steroid before aspiration
  3. Give antibiotics for a week before any sampling
  4. Use a normal radiograph to exclude infection
  5. Obtain synovial fluid promptly, then start appropriate empiric antibiotics
Reveal answer and explanation
Correct answer

Obtain synovial fluid promptly, then start appropriate empiric antibiotics

When there is no sepsis, sampling before antibiotics improves culture yield without delaying necessary care.

Understanding the options

Obtain synovial fluid promptly, then start appropriate empiric antibiotics
When there is no sepsis, sampling before antibiotics improves culture yield without delaying necessary care.
Wait several days for spontaneous improvement
Suspected joint infection requires prompt assessment.
Inject intra-articular steroid before aspiration
Steroids should not be injected into a possibly infected joint.
Give antibiotics for a week before any sampling
This can reduce microbiologic yield.
Use a normal radiograph to exclude infection
Early radiographs can be normal.
