Anticoagulation monitoring

Choose the single best answer, then reveal the explanation.

A 62-year-old man with a mechanical heart valve has repeatedly stable anticoagulation on warfarin. Rifaximin is added for recurrent hepatic encephalopathy, while his warfarin dose and diet remain unchanged. Which follow-up measure most directly addresses a reported interaction between these medicines?

  1. Measure serum rifaximin routinely before every dose
  2. Increase warfarin automatically before checking coagulation
  3. Replace INR testing with platelet counts alone
  4. Measure activated clotting time as the sole outpatient test
  5. Monitor INR and adjust warfarin according to the measured response
Reveal answer and explanation
Correct answer

Monitor INR and adjust warfarin according to the measured response

Changes in anticoagulant response have been reported; the direction should not be assumed.

Understanding the options

Monitor INR and adjust warfarin according to the measured response
Changes in anticoagulant response have been reported; the direction should not be assumed.
Measure serum rifaximin routinely before every dose
Routine therapeutic drug monitoring of rifaximin is not the recommended strategy.
Increase warfarin automatically before checking coagulation
Empiric escalation could cause bleeding if the response increases.
Replace INR testing with platelet counts alone
Platelet number does not measure warfarin anticoagulation.
Measure activated clotting time as the sole outpatient test
INR remains the relevant routine measure for warfarin control.
